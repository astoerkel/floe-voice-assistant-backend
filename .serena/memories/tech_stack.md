# Technology Stack

## Backend Framework
- **Runtime**: Node.js (>=18.0.0)
- **Framework**: Express.js 4.x
- **Language**: JavaScript (ES6+)

## AI/ML Services
- **LangChain**: AI agent framework
- **OpenAI**: GPT-4 for language processing, Whisper for speech-to-text
- **Anthropic**: Claude for additional AI capabilities
- **Google Cloud**: Text-to-Speech API

## Database & Storage
- **PostgreSQL**: Primary database
- **Prisma**: ORM for database operations
- **Redis**: Caching and queue management
- **Railway Volumes**: File storage for audio files

## Authentication & Security
- **JWT**: JSON Web Tokens for authentication
- **Apple Sign In**: iOS authentication
- **Google OAuth**: Google account integration
- **Passport.js**: Authentication middleware
- **Helmet**: Security headers
- **bcryptjs**: Password hashing

## Real-time & Queue
- **Socket.IO**: WebSocket connections
- **Bull/BullMQ**: Background job processing
- **IORedis**: Redis client

## External Integrations
- **Google APIs**: Calendar, Gmail integration
- **Airtable**: Database integration
- **OpenRouter**: AI model routing

## Development Tools
- **Nodemon**: Development server with auto-reload
- **Jest**: Testing framework
- **Supertest**: API testing
- **Winston**: Logging
- **Morgan**: HTTP request logging
- **Joi**: Data validation
- **Express Validator**: Request validation
- **Express Rate Limit**: API rate limiting
